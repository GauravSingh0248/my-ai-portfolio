## 2. Customer Churn Prediction

This project predicts whether a customer is likely to leave a bank service (`Exited = 1`) using machine learning.

The implementation is notebook-based and covers an end-to-end workflow:

- Data loading and cleaning
- Exploratory data analysis (EDA)
- Feature preparation and encoding
- Model training and tuning
- Performance evaluation

**GitHub:** https://github.com/GauravSingh0248/Project---Customer-Churn-Prediction

## 3. Machine Learning Based Auto-Tuning Compiler

This project is an attempt to make compiler optimization selection easier and smarter using Machine Learning.

In C programming, choosing the right GCC optimization flag (`-O0`, `-O1`, `-O2`, `-O3`) is not always obvious. Many times, people use a flag by guesswork. The goal of this project is to reduce that guesswork with a data-driven approach.

**GitHub:** https://github.com/GauravSingh0248/autotuning-compiler-ml
